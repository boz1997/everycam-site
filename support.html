Support

ShareCam is built and supported by a solo developer — you write, I answer. E-mail everycam.app@gmail.com and include your event code if your question is about a specific event.

Quick answers

A guest can't join — what should they check?

The 6-character code has no confusing characters (no 0/O or 1/I). Make sure the event isn't paused for new joins (Event → Settings → "Pause new joins"), and that they're typing the code from the table card, not the event name.

Where are my photos stored?

In your event's gallery for the storage window of your package (7 days to 12 months). You'll always be warned in the app before storage expires — nothing is deleted silently. You can download everything to your phone with one tap (Gallery → "Save all").

How do I print table cards?

Event → QR / Invite → Create Share Card → pick a design → Print 4 per page (PDF). The PDF places four cards on an A4 sheet with cut marks.

Can guests see each other's photos?

Only if you want them to. An open gallery is a live shared album; in piggy-bank mode only you see everything until you reveal the gallery — manually or on a schedule.

How do refunds work?

Purchases go through Apple, so refunds are requested from Apple at reportaproblem.apple.com. If something went wrong on our side, write to us first — we'll make it right.
